P1: Technical Background
P2: The proposed system is a web-based platform developed for the Barangay Santolan PWD Association. It is used to manage member records, assistance applications, programs, events, announcements, reports, and system activities through a centralized information management environment.
P3: The system is built using Django and Django REST Framework for application development, MySQL for data storage, Bootstrap 5 for the user interface, and Chart.js for data visualization. It follows a Three-Tier Architecture consisting of the Presentation Layer, Application Layer, and Data Layer.
P4: The system includes an Equity Weighted Analytics Module that evaluates assistance applications using general criteria and program eligibility requirements. The generated results are presented to administrators as part of the application review process.
P5: Authorized administrators use protected, role-based accounts to manage records and reviews. Members use the approved public application processes without member login accounts. System activities are recorded through the Audit Trail Module, while reports and analytics may be generated through the Reporting Module.

P102: Calculation Boundaries
P103: If xmax = xmin for a criterion, the formula divides by zero. Stop the example calculation for that case until an explicit constant-column rule is selected; do not invent a zero or maximum value.
P104: Do not calculate from missing, disputed, or stale required inputs. An unknown value is not the number zero.
P105: If this dataset-based method is used and the accepted pool or its values change, recompute the shared bounds and all affected results consistently. Preserve the earlier run.
P106: Store sufficient precision and round only displayed values. Use exact 2/3 in this worked example, not a prematurely rounded 0.67.
P107: Dataset-derived bounds are retained for fidelity to this source example. This document does not replace an existing software configuration that requires separately approved fixed bounds.
