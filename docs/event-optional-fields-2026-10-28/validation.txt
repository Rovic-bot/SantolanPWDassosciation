Optional scheduled-event details and modal cleanup — 28 October 2026

Owner authorization
The owner explicitly confirmed that Target Audience and Who May Participate are
optional, requested removal of the event image-description field, and requested
removal of Manage event and the bottom Close button from the information modal.
This supersedes the earlier scheduled-event requirement for those two text fields.
It does not change annual-observance authoring, RSVP, admission rules, membership,
linked-program protection, attendance, selection or scoring.

Cause and correction
The form already allowed blank audience/participation text, but publication still
required it, and the public list excluded records with either field blank. Both
checks are corrected for scheduled Events. General/Specific category remains
required before publication; uncategorized historical records retain their prior
listing behavior. Blank optional details are omitted from scheduled-event detail
displays rather than shown as missing-publication warnings. No participation rules
or audience content were fabricated.

Image-description handling
The create/edit form no longer exposes or requires image_alt. The existing database
field and audit coverage remain. New/replacement images get generic accessible
text based on the event title. Existing descriptive text is preserved when the
photo is unchanged. Image removal clears its text. Existing images with blank
stored text use the same title-based template fallback and can be published.
The fallback identifies the event; it does not infer what an image depicts.
File validation, size/pixel limits, access-checked image routes, missing-file
checks, atomic audit recording and upload rollback remain intact. Publication
does not rewrite image fields, preserving the guarded writer's scope.

Modal
Manage event and the bottom Close button are removed. Authorized users retain
Edit event. The top-right X, Escape, backdrop dismissal and keyboard focus behavior
remain. The modal is centered on the full viewport at desktop and mobile sizes.
