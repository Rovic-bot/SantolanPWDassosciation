# Santolan PWD Association · blue glass redesign

[Local system](http://127.0.0.1:8013/) · [Desktop and mobile screenshot gallery](index.html) · [Side-by-side home preview](preview.jpg)

Implemented in the existing Django application on `fix-UI`. Public pages use navy typography on a pale blue canvas, translucent panels with reflective edges for navigation and tools, and opaque paper surfaces for records, instructions, forms and results. The two staff themes and staff actions use the same five brand colors without changing the workspace hierarchy. Success, warning and error states retain separate colors and labels.

**System coverage.** Shared palette: navy `#03195B`, royal `#0B2CB1`, primary `#1951FC`, bright `#3781FC`, ice `#CBE9FD`. Public and member-facing application, verification, tracking, confirmation and failure screens inherit the public theme. Staff sign-in, password screens, the administration workspace, native Django admin and staff-managed member records use shared brand tokens. There is no separate member-login portal in this system. The change does not add one or change permissions. Existing eligibility, verification, review and publication rules remain authoritative.

**Assets.** The official association seal remains in its original colors. The home gathering, About walk, Events walk and Programs assistance-supplies photographs were taken from the project's existing approved public files corresponding to `Assets/photo_10_2026-10-27_06-00-22.jpg`, `photo_12_2026-10-27_06-00-22.jpg`, `photo_13_2026-10-27_06-00-22.jpg` and `photo_5_2026-10-27_04-10-15.jpg`. The public derivatives preserve the existing face blurring in the pixels. Each has 640px and 1080px WebP options, an existing JPEG fallback, declared dimensions and contextual alternative text. Individual scheduled events use only their own approved media when present. All four source images remain unchanged.

**Local preview.** The retained system runs at [127.0.0.1:8013](http://127.0.0.1:8013/). To restart it from the project directory, run `.venv\Scripts\python.exe -B scripts/current_development.py restart`. The screenshot content is the existing local development dataset. No production deployment or application database migration was performed.

**Reproducing the browser checks.** `scripts/public_glass_browser_qa.cjs` accepts a mode (`capture`, `enlarged`, `linked`, `flows`, `boundaries`, `staff` or `states`) and a viewport width. The default output is ignored `.local/public-glass-qa/`; capture at 1440 before the linked run to collect the current public URLs. For private presentation fixtures, run `.venv\Scripts\python.exe -B scripts/public_glass_states.py`. The `staff` run uses the disposable `scripts.admin_theme_fixtures` Django test output. Native screen-reader testing on physical devices and third-party service availability were not independently verified.
