Live sources and definitions
Official members, accepting programs, events and Desk request definitions remain.
New members this year counts recorded joining dates from local January 1 through
the current timestamp, including members archived since joining. This current-year
snapshot remains independent of the selected activity dates.
Pending photo verification counts that exact existing application status; it is
not a newly invented collection of pending workflow stages. Completed applications
counts the existing COMPLETED status in the submission-date cohort. The total
application count remains visible in the application chart and completion summary.
Completion bars show completed / submitted applications for each actual program,
using current status and the selected submission cohort. They do not claim program
closure, assistance delivery or invented completion rates for example categories.
Release mix groups successful, non-voided receipts by recorded assistance_type and
actual delivery dates. It counts releases, not currency values or selected people.
Disability rings use each category's distinct member count / current members, so
multiple classifications can overlap without creating a false pie partition.
Program rings retain Draft/Published/Cancelled/Archived labels. Desk gauge shows
Closed / all requests, retaining actual status labels, not inferred resolution.
Scatter trend is least-squares across observed aggregate points within their x
range; omitted with insufficient x variation. It is descriptive, not a prediction
or selection rule. Coincident point labels wrap within the chart.

Program filter
The real GET filter lists programs only for staff with dashboard and program-view
permissions. Invalid or unauthorized selections fail validation; direct aggregation
also requires program-view permission. It scopes application, eligibility, release,
program-status and capacity queries. Membership, ages, events and Desk requests
remain association-wide, as explained in the form. Per-module permission gates,
restricted/unavailable/error states, private data boundaries and existing date
semantics remain. Dashboard queries only read records; no workflow service runs.
