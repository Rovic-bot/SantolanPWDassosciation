## Required technical safeguards before release

Keep the current reference-only denial, separate private-document permission, original receipt projection, CSRF, audit failure rollback, stale-version checks and concurrency protections. Resolve the new shared-device finding with extension code only under a later scoped instruction. Do not weaken the public access model to make expired receipts retrievable.

No changes to EWAF, historical references, ordinary program matching, protected source writers, startup guard, historical migrations or eight-group navigation are needed or authorized by this review. If a later bridge cannot preserve those contracts, leave it blocked and report the dependency.

Record each approved parameter with its unit, justification, responsible reviewer, affected environment and tested boundary cases. Record the expected effects of policy changes on existing sessions and applicant guidance. Approval must describe usable values and behavior, not merely approve the word “unset.”
