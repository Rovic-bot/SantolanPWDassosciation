Owner-requested changes

The application change-report dropdown defaults to No changes to report and
offers only unchanged/changed. Bound invalid submissions retain the selected
answer. New uncertain submissions are rejected by the choice field; historical
uncertain declarations and their existing reviews remain readable. Changed
reports still require details. The two requested explanatory paragraphs were
removed.

The private ranking workspace automatically reads household income, 4Ps
participation, employment status and household size from the current member
record. Missing values remain Not recorded; zero income and No participation
are preserved. The table distinguishes registration information from accepted
scoring inputs, including inputs from the retained non-dataset workflows.
GET does not create findings, change eligibility, or authorize a calculation.
Existing accepted inputs are displayed from inventory, not overwritten by the
current registration record. PA still comes from successful release records
under the approved calculation contract, rather than invented defaults.

Removed the misleading Complete the input review placeholder. The page links
to the member record, program settings and scoring configuration. Eligible
applications with a locked, complete configuration link directly to their
dataset, registered-input or legacy evidence review, as applicable and only
for officers with review permission. Draft/source-only configurations do not
show an unavailable review link. Membership provenance, changed program terms
and outstanding input reviews now have distinct messages. The legacy fallback's
missing criterion assessments are not presented as missing registration data
when no input-review contract exists. Raw engine blockers remain unchanged.
