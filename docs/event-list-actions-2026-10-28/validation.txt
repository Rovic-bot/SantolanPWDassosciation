Event list actions and centered information modal — 28 October 2026

Owner request
Add a publication action to scheduled-event rows and open event information in
a modal centered on the screen.

Implemented
- Events now has an Actions column with View details and, for authorized staff
  on unpublished records, Publish event. Already published rows omit Publish.
- Both the event title and View details open the same centered, scrollable
  Bootstrap modal. It displays the title/status, optional photo, schedule,
  location, capacity, audience, participation information and description.
- The modal is rendered outside the main layout so the sidebar cannot shift
  its center. Close, Escape and keyboard focus trapping/return work. Edit event
  and Manage event links retain access to the existing authorized workflows.
  Title/detail links retain normal review-page destinations without JavaScript.
- Row publication uses the existing permission-checked, versioned, audited
  publish_event action, with no reason field or extra confirmation. Success and
  validation errors return to the Events list. The return target is a fixed
  internal route, not an arbitrary submitted URL.
- Existing required-content checks remain. The assistant did not publish the
  real draft, supply missing content or change publication policy.
