Public portal visual editor - 2026-11-06

Owner scope
Content Management displays the public portal tabs. Staff open a page, edit its
text and pictures in the actual page layout, preview, and explicitly save.

Implemented
- Eight current public pages: Home, About, Announcements, Events, Programs,
  Results, Membership & PWD ID, and Resources & Help.
- Actual public templates in a permission-checked preview frame; editable copy
  and picture controls, plain-text editing, Preview, Discard changes, and Save.
- Existing content view/change/publication permissions remain authoritative.
  Publishers save publicly; editors without publication permission save private
  drafts. A publisher can save an existing draft without making another edit.
- Page versions prevent stale overwrites. Every save records actor, version,
  and before/after snapshots transactionally. New upload cleanup on rollback.
- PNG/JPEG uploads use the existing image validation/re-encoding pipeline.
  Private storage and token-checked views serve current published artwork;
  draft artwork requires content access. Replacement history is retained.
- Existing program, announcement, event, application and result records continue
  to supply dynamic content. Public navigation and workflow actions remain intact.
- Legacy content edit/history URLs remain available for existing records.
