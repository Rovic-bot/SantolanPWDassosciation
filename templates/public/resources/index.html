{% portal_text "text_011" %}COMMON QUESTIONS{% endportal_text %}

{% portal_text "text_012" %}Frequently asked questions{% endportal_text %}

{% portal_text "text_013" %}Choose a question to read its answer.{% endportal_text %}

1

{% portal_text "text_014" %}Do I need an account?{% endportal_text %}

{% portal_text "text_015" %}No member account is needed. Program applications and referral requests require a check of your Association membership using your registered details.{% endportal_text %}

2

{% portal_text "text_016" %}Which application do I need?{% endportal_text %}
  • {% portal_text "text_017" %}Association membership:{% endportal_text %} {% portal_text "faq_membership_description" %}apply to join the Association, then visit the Help Desk for review.{% endportal_text %}
  • {% portal_text "text_018" %}PDAO PWD ID:{% endportal_text %} {% portal_text "faq_pdao_description" %}prepare or submit a separate form for staff review and forwarding. PDAO makes the government ID decision.{% endportal_text %}
  • {% portal_text "text_019" %}Program application:{% endportal_text %} {% portal_text "faq_program_description" %}apply for a specific published program.{% endportal_text %}
  • {% portal_text "text_020" %}Assistance or referral request:{% endportal_text %} {% portal_text "faq_referral_description" %}ask for guidance about a concern. This is not a program application.{% endportal_text %}
3

{% portal_text "text_021" %}Does an online submission mean I am approved?{% endportal_text %}

{% portal_text "text_022" %}No. Keep your receipt and follow the next steps. Membership needs onsite verification and a staff decision. PDAO handles PWD ID approval. Program applications undergo review before any final selection.{% endportal_text %}

4

{% portal_text "text_023" %}How do I follow up or correct my information?{% endportal_text %}

{% portal_text "text_024" %}For a program application, use the private application check if available. For membership or PDAO forms, bring your reference to the Help Desk. For a referral request, follow the email or Help Desk instructions on your receipt.{% endportal_text %}

{% portal_text "text_025" %}Contact the Help Desk about corrections or a lost reference. A reference alone does not give access to private information.{% endportal_text %}

5

{% portal_text "text_026" %}Can someone help me use this website?{% endportal_text %}

{% portal_text "text_027" %}Ask a guardian, caregiver, or the Help Desk for assistance. Use Display to enlarge text or increase contrast. To listen to text, highlight it and choose Read aloud when your browser supports it.{% endportal_text %}
